# CODSOFT Data Science Internship

This repository contains the projects completed as part of the CodSoft Data Science Internship.

## Projects

### 1. Titanic Survival Prediction
- Built a Logistic Regression model to predict passenger survival.
- Achieved 79.89% accuracy.
- Performed data cleaning, visualization, and model evaluation.

### 2. Iris Flower Classification
- Built a Random Forest Classifier to classify iris flowers.
- Achieved 100% accuracy.
- Used flower measurements to predict species.

### 3. Sales Prediction Using Python
- Built a Linear Regression model to predict sales.
- Achieved R² Score of 89.94%.
- Analyzed the relationship between advertising and sales.

## Technologies Used

- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
